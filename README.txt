REGISTRO LAVORAZIONI v2

Funzioni aggiunte:
- statistiche mensili: giorno più produttivo, giorno meno produttivo, medie e grafico;
- prezzi configurabili per Impianti, Guasti, Task, TTO e Attivazioni;
- calcolo del valore in euro per ogni giornata e del totale mensile;
- esportazione CSV/Excel con valore giornaliero;
- BACKUP: crea un file JSON salvabile sul telefono;
- RIPRISTINO: seleziona il file JSON dal telefono per ripristinare lavorazioni e prezzi;
- stesso appId: it.registrolavorazioni.app, quindi l'aggiornamento può mantenere i dati locali se l'app non viene disinstallata.

Prezzi iniziali impostati: Impianti 110 €, tutte le altre attività 30 €. Sono modificabili dall'app.
